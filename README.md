# FYP_FruitPicking
## A benchmark for different path planning algorithms for fruit picking for Robotics and Intelligent Devices final year project 2026
PREREQUISITES: pybullet_planning: https://github.com/yijiangh/pybullet_planning?tab=readme-ov-file, Gymnasium, Stable Baselines3

to run bi-rrt and lazy-prm benchmark go into Scripts and type - python3 birrt.py/lazy_prm_t.py
To train mode with fixed fruit pos run train_rl.py in RL folder
To train with domain randomisation after fixed model is trained run the other train file in the RL folder
